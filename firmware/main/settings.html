声音与屏幕

音色为当前订阅接口支持的 9 个预设。语速、回答长短和语言是模型对话指令，不是精确音频参数。保存后，在设备 Conversation → New chat 中应用新设置并清空原上下文。

自动结束时长在下一次对话生效。上下键调整的音量也会自动保存。音量范围为 0–100，0 为静音。

操作指南

短按 OK 打开多级设置，上下键选择，OK 进入，每层有 Back 返回。聊天页上下键调音量；长按上下键不再有独立功能。

按住说话：按住 OK 约半秒，看到 RECORDING 后说话，松开发送。录音暂存在服务器内存，松开后才送入模型；较长录音会增加等待时间，最长 60 秒后自动发送。接通期间同样可以录音。按住 OK 可打断回复并录制新问题。

畅聊：在 Conversation 中选择 Live chat 后新开对话；看到 LISTENING 后直接说话。Full duplex 为实验选项，允许模型说话时收音和插话。进入菜单会暂停畅聊收音，返回恢复。结束或清空上下文均在 Conversation 中操作。

独立电源键由硬件控制，约 0.5 秒开机、约 2 秒关机。当前硬件接口没有可复用的电源短按事件。设备只显示英文操作指南、菜单和必要状态。

无线升级

先结束对话，进入设备设置 Device → Phone / firmware update 开放升级，5 分钟内选择固件并上传。升级期间保持供电。

更换 Wi-Fi

连接失败时设备会显示配网二维码。也可短按 OK 进入 Network → Wi-Fi setup，扫码连接 GPT-Passport 热点；如手机未自动打开页面，按设备 OK 查看第二个二维码并扫码填入 Wi-Fi。
