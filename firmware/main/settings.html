声音与屏幕

畅聊始终保持双向收音和播放，可直接插话。

音色为当前订阅接口支持的 9 个预设。语速、回答长短和语言是模型对话指令，不是精确音频参数。保存后，在设备 Conversation → New chat 中应用新设置并清空原上下文。

自动结束时长在下一次对话生效。设备设置中的音量调整会自动保存。音量范围为 0–100，0 为静音。

操作指南

按住 OK 说话，松开发送。按下即缓存声音，约 0.2 秒确认后上传。短按 OK 在思考或播放时停止当前交互并保留上下文，空闲时只唤亮屏幕。

上键音量 +5，下键音量 −5，长按连续调整。下键和 OK 从起始一起按住约 0.8 秒打开快捷菜单；途中加按不会打开菜单。菜单首项开启／退出畅聊，菜单内上下选择、短按 OK 确认、长按 OK 返回。

畅聊持续收音，助手说话时也可插话。进入菜单暂停收音，返回恢复。畅聊时按住 OK 切回按住说话，保留上下文。新开对话与结束会话在 Conversation 中。开机默认按住说话，独立电源键保持硬件开关机。

无线升级

先结束对话，进入设备设置 Device → Phone / firmware update 开放升级，5 分钟内选择固件并上传。升级期间保持供电。

更换 Wi-Fi

连接失败时设备会显示配网二维码。也可按住下键 + OK 打开快捷菜单，再进入 Network → Wi-Fi setup，扫码连接 GPT-Passport 热点；如手机未自动打开页面，按设备 OK 查看第二个二维码并扫码填入 Wi-Fi。
